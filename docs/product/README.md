# IMBOP Product

IMBOP is **Institutional Economic Network Infrastructure**.

Core model:

**Institution → Authorised Members → Businesses → Opportunities**

The product sells institutional outcomes, not a collection of disconnected software features.

## Core product loop

**INSTITUTION → AUTHORISE → ONBOARD → PROFILE → BUSINESS → OFFER / NEED / OPPORTUNITY → REVIEW → PUBLISH → DISCOVER → ENQUIRE → CONNECT → BENEFIT → REPORT**

## Core principle

> **Application ≠ Publication**

An application enters an institutional review workflow. Publication is an institutional governance decision.

## Commercial model

The institution is the IMBOP customer.

Individual members are not ordinarily billed for participation. The commercial unit is **IMBOP Onboards**.

The current plan structure is:

| IMBOP Onboards | Monthly Plan |
|---|---:|
| 0–50 | FREE |
| 51–100 | KES 7,500 |
| 101–500 | KES 15,000 |
| 501–1,000 | KES 25,000 |
| 1,001–5,000 | KES 50,000 |
| 5,001–10,000 | KES 75,000 |
| 10,001–25,000 | KES 100,000 |
| 25,001–50,000 | KES 150,000 |
| 50,001+ | NEGOTIATED |

When an institution first crosses the 50-Onboard threshold, the transition month uses a **KES 5,000 total discounted transition invoice**. It is not added to the normal plan fee.

## Billing architecture

The canonical billing loop is:

**PRICING → BILLING ACCOUNT → INVOICE → PAYMENT INTENT → PAYMENT → ALLOCATION → RECEIPT → RECONCILIATION → REFUND → AUDIT**

Payment methods are provider-neutral at the ledger level. Current rails/foundations include M-PESA, bank transfer, Airtel Money and card configuration points.

Live provider activation remains configuration- and evidence-dependent.

## Governance

The institution governs member and economic-content publication.

SE governs platform admission, institution lifecycle, platform permissions and platform-level commercial controls.

The billing layer follows the same rule:

> **The UI may request an operation; controlled database functions and platform operations determine whether the operation is allowed.**
