# IMBOPwiki — Integrations
**Status:** Frozen for MVP engineering

## Ladder
1. LINK
2. WIDGET / EMBED
3. API INTEGRATION
4. NATIVE IMBOP ACTION
5. DEEP WORKFLOW INTEGRATION

## WhatsApp
WhatsApp is complementary: distribution, notification, informal coordination and opt-in reach. IMBOPwiki remains authoritative for governed knowledge and institutional memory. Messages should point to authorized IMBOP records.

## Economic graph
Wiki content may reference businesses, business profiles, offers/needs, opportunities, enquiries, introductions, institutions and communities. The target remains authoritative for its lifecycle and authorization.

## External profiles
Start with links for LinkedIn and similar services. Embeds require separate product/security justification.

## API
Consumers receive only records they are authorized to access. Search indexes, caches, notifications and exports are never alternate authorization paths.

## No premature integration
MVP does not require WhatsApp automation, SMS, broad social integrations, marketplace syndication, AI matchmaking, blockchain or microservices.
