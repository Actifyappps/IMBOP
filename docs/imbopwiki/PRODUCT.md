# IMBOPwiki — Product Freeze
**Status:** Frozen for engineering planning

## Definition
IMBOPwiki is the shared knowledge, collaboration and institutional-memory layer of IMBOP.

**Institution → Authorised Members → Businesses → Opportunities**
+
**Knowledge → Communities → Discussion → Collaboration → Institutional Memory**

Economic loop: **KNOW → DISCUSS → DISCOVER → ENQUIRE → CONNECT → ACT**

## Boundary
IMBOPwiki is in-app, governed, attributable, searchable and connected to IMBOP economic objects. It is not a standalone wiki, generic social network, WhatsApp replacement, unrestricted discussion board, document dump, second economic-object database or automatic publication channel.

## MVP surfaces
1. Wiki home/discovery
2. Knowledge item view
3. Communities
4. Community membership
5. First-class discussions
6. Author contribution workspace
7. Review/publish queue
8. Existing IMBOP in-app notifications
9. Links to authorized IMBOP economic records
10. Public published-content discovery

## MVP content types
- ARTICLE
- OPPORTUNITY
- QUESTION
- RESOURCE
- ANNOUNCEMENT
- EVENT

A discussion is a first-class collaboration object, not a content type.

## Product rule
A feature belongs only if it strengthens IMBOP as a governed institutional economic network. Consumer-social features without institutional value are outside MVP.
